## Principles you can inspect in the code

- A test should demonstrate that it can catch the failure it claims to prevent.
- Missing evidence is an explicit state, never an invented zero or a reassuring badge.
- A decision that must be reproducible deserves an explicit rule and a traceable source.
- Privacy boundaries apply to logs, reports and screenshots as well as databases.
- A polished interface must also explain delays, uncertainty and recovery.
